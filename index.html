Simpan bersama lewat GitHub

Dengan token GitHub, tombol 💾 Simpan menyimpan data ke repo perencana-distribusi, sehingga semua orang yang membuka link web ini melihat data terakhir. Tanpa token, web hanya menampilkan data bersama dan perubahan Anda tersimpan di browser ini saja.

Cara membuat token (sekali saja):

  1. Buka github.com/settings/personal-access-tokens/new (login sebagai pemilik repo).
  2. Isi nama token, misalnya "Perencana Distribusi", dan pilih masa berlaku.
  3. Di Repository access pilih Only select repositories, lalu pilih perencana-distribusi.
  4. Di Permissions → Repository permissions, ubah Contents menjadi Read and write. Yang lain biarkan.
  5. Klik Generate token, salin token (diawali github_pat_), lalu tempel di bawah.

Token hanya disimpan di browser ini, tidak pernah masuk ke kode atau repo. Repo ini publik, jadi data yang disimpan (nama store, alamat, koordinat) bisa dibaca siapa saja.
